# Product Roadmap

## Roadmap principle

Each release must complete an end-to-end customer outcome. Do not add broad connector coverage before the closed-loop assurance workflow is reliable.

## R0: Documentation and platform foundation

- Approved product and architecture baseline
- Repository access and branch controls matching the actual GitHub configuration
- Monorepo scaffold
- CI and documentation validation
- PostgreSQL foundation
- Synthetic seed data
- Enforced OIDC identity, scoped authorization and encrypted secrets
- Containerized local environment

## R1: Closed-loop delivery assurance

- Jira Cloud
- Excel/CSV portfolio input
- Canonical Project Model
- Fact and Evidence Ledger
- Source authority and conflicts
- Freshness and first health rules
- Contextual update requests
- Reminder and PM escalation
- Free-text extraction and clarification
- Approval diff
- Jira comment write-back
- Action receipts
- PM action queue
- Evidence-backed leadership Q&A
- Live dashboard
- PowerPoint/PDF management snapshot
- Shadow mode
- Customer-hostable package

## R2: Microsoft enterprise collaboration

- Outlook/shared mailbox
- Microsoft Graph mail sending and reply capture
- Microsoft Teams notifications and interactions
- SharePoint and OneDrive evidence
- Enterprise identity administration extensions beyond R1 basic user/group mapping
- Customer holiday calendars beyond R1 weekday and quiet-hour scheduling
- Customer-branded templates

## R3: Portfolio intelligence

- Cross-project dependency propagation
- Advanced reported-versus-evidence checks
- RAID hygiene
- Unlogged risk detection
- Forecast trend analysis
- Portfolio recommendations
- Leadership decision workspace
- Portfolio-level Q&A

## R4: Connector expansion

Prioritize based on paid demand:

- ClickUp
- Trello
- monday.com
- Asana
- Slack
- Confluence
- Microsoft Planner/Project where feasible
- Additional spreadsheet and document formats

## R5: Enterprise productization

- Signed offline licence files
- Hardened installer and upgrade controller
- Source-access commercial tier
- Source-code escrow support
- MCP server with controlled product tools
- Optional Atlassian/Rovo interaction layer
- Advanced observability and support bundle
- Multi-environment promotion
- Partner implementation toolkit

## Future AvalaOS integration

- Approved initiatives sent from AvalaOS to the delivery portfolio
- Delivery assurance status returned to AvalaOS
- Benefit and outcome evidence passed to AvalaOS Prove
- Shared identity and design patterns only where commercially justified
